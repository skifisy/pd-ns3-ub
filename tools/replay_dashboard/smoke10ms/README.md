# 10 ms 合成 smoke 数据

此目录由确定性 CSV 写入脚本生成，不是 ns-3 实验结果，不证明性能收益。
持续 1 秒；基础间隔 10 ms；TE 在 0.1035 s 发布，TOE 在 0.2535 s 生效，事件边界拆分窗口。
焦点 L10→L11；TE 使用 L12 中转；TOE 将直连从 1 条改为 2 条，并保持物理端口匹配。
仿真口径每条 Fabric 链路 4 Mbps；throughputScale=100000，页面显示为 400 Gbps。
接入发送吞吐包括 0→10 业务发送和 1→11 的合成反向流量。
ECMP 有一个未完成任务，三组共同完成任务为 5 个。

自行运行：`python server.py --smoke`。本次交付未运行导入、服务或测试。
